The four rejected oracle candidates remain explicit negative design constraints:

- duplicate open lease slots alone are not a reaping license;
- a lease naming a node absent from the usable snapshot is not necessarily an
  orphan (cordoned nodes are omitted);
- a spare may legally exist before its active lease; and
- a Running run may temporarily have zero active leases while a replacement pod
  awaits scheduler PreBind.

Any formal property that excludes one of those states is a reaper, not a proof.
